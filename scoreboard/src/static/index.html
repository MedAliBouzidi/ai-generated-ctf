🏁 VulnLab CTF Rules of Engagement

VulnLab CTF is an isolated educational cyber practice range. All services run strictly on 127.0.0.1 and have isolated bridge networks.

  • Flag Format: VULNLAB{<32_lowercase_hex_chars>}
  • Points Structure: Easy = 100 pts, Medium = 200 pts, Hard = 300 pts.
  • Hints Penalty: Each challenge features up to 2 hints. Unlocking a hint permanently deducts 25% of points upon solve (Easy: -25 pts, Medium: -50 pts, Hard: -75 pts).
  • First Blood: The first hacker to solve any challenge earns the 🩸 First Blood honor and badge.
  • Rate Limiting: Maximum 10 flag submissions per minute per player / IP to prevent automated brute-forcing.
  • Zero Plaintext Storage: The scoreboard stores only HMAC-SHA256 hashes of flags, keyed with SCOREBOARD_SECRET. Plaintext flags are never saved to database or logs.

🎯 Target Applications

  • Blog SQLi (Port 8001): SQL injection vulnerabilities in login, union search, and stored comments.
  • Notes IDOR (Port 8002): Insecure direct object references and role escalation flaws.
  • File Share (Port 8003): Path traversal, arbitrary file upload, and MIME validation bypasses.
  • Shop Auth (Port 8004): JWT alg-none confusion, brute force bypass, and predictable reset tokens.
  • Ping Tool (Port 8005): Command injection, SSRF, and reflected XSS vulnerabilities.

⚙️ Scoreboard Administration

Use the administrative reset tool to clear all player submissions, hints, and leaderboard standings without restarting Docker containers.


💻 API Admin Reset Command

You can also reset the scoreboard programmatically via curl:

curl -X POST http://127.0.0.1:8000/api/admin/reset \
  -H "X-Admin-Token: $SCOREBOARD_SECRET" \
  -H "Content-Type: application/json"
